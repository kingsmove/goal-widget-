# RTL (건안기·도계기·컴활 1급·단어장 통합)

건설안전기사 · 도시계획기사 · 컴활 1급 기출 CBT + 단어장(VOCA)을 합친 학습 앱. 패키지는 기존 VOCA(`com.jongjun.voca`)를 그대로 써서, 폰에 있던 단어장 기록을 자동으로 옮겨 온다.

- 앱 본체: `app/src/main/assets/index.html` (PC용 `건안기.html`과 같은 파일, 폰트·문제·단어 내장)
- 이 브랜치(vocab-app)에 push하면 GitHub Actions가 APK를 빌드해 Release(voca-N)에 올림
- 만드는 방법: 바탕화면 `기사 필기 준비/_앱 제작 도구/README.md`
